# Documentation

Use this directory by question, not by file name.

## Guides

These are task-oriented documents for choosing and applying a workflow:

- [Vibecoding Setup Guide](./vibecoding-setup-guide.md): choose a bundle and set
  up an end-to-end claude-toolbox workflow

## Plugin Docs

Detailed installation, configuration, and examples live in each plugin's own
directory under `plugins/<plugin-name>/README.md`.

Use plugin docs when the question is about one specific plugin's behavior.

## Reference

The `docs/claude/` directory contains Claude Code reference material relevant to
this repository:

- [Skills](./claude/skills.md)
- [Slash Commands](./claude/slash-commands.md)
- [Subagents](./claude/sub-agents.md)
- [Hooks](./claude/hooks-guide.md)

Use reference docs when the question is about format, syntax, or Claude Code
capabilities rather than repo-specific workflow choices.
